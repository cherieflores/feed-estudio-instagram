GUÍA PARA SUBIR ESTA NUEVA ESTRUCTURA A GITHUB

IMPORTANTE:
No necesitas saber programar. El paquete ya está organizado.

RECOMENDACIÓN MÁS SEGURA:
No borres todavía los archivos antiguos. Primero sube la nueva estructura,
comprueba que /hombres/ funciona y después limpiamos lo anterior.

PASOS:
1. Descomprime este ZIP.
2. En GitHub abre tu repositorio feed-estudio-instagram.
3. Pulsa Add file > Upload files.
4. Arrastra TODO el contenido que está dentro de esta carpeta:
   - index.html
   - .nojekyll
   - README.md
   - carpeta hombres
   - carpeta shared
5. Baja hasta Commit changes y confirma.
6. Espera 1–2 minutos.
7. Abre:
   https://TUUSUARIO.github.io/feed-estudio-instagram/hombres/

Después de verificar que funciona, puedes borrar el antiguo README.txt y la
antigua carpeta /images de la raíz. No afectan al nuevo feed aunque permanezcan ahí.

CÓMO BORRAR UN ARCHIVO EN GITHUB:
1. Abre el archivo.
2. Arriba a la derecha usa el menú de tres puntos (...) o el icono de papelera.
3. Elige Delete file.
4. Baja y pulsa Commit changes.

CÓMO BORRAR LA CARPETA ANTIGUA /images:
GitHub no borra una carpeta vacía directamente: debes eliminar sus archivos.
Como son varios, es más seguro dejarlos temporalmente. No se usan por /hombres/.
Cuando terminemos ambas versiones podemos hacer una limpieza final del repositorio.
